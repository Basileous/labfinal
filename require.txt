Symbolic Mode 
Symbolic mode uses letters to add (+), remove (-), or set (=) permissions. 
$ chmod u+x script.sh       # Add execute for the owner (user) 
$ chmod g-w notes.txt       # Remove write from the group 
$ chmod o+r report.txt      # Add read for others 
$ chmod a+x deploy.sh       # Add execute for all (user, group, others) 
$ chmod u=rwx,g=rx,o= file  # Set exact permissions for each category 
 	

Numeric (Octal) Mode 
Numeric mode uses a 3-digit number. Each digit is calculated by adding: r=4, w=2, x=1. 
 
Number Binary Permissions 
7 111 rwx  read, write, execute 
6 110 rw-  read and write only 
5 101 r-x  read and execute only 
4 100 r--  read only 
0 000 ---  no permissions at all 
 
$ chmod 755 script.sh    # Owner: rwx  Group: r-x  Others: r-x 
$ chmod 644 notes.txt    # Owner: rw-  Group: r--  Others: r-- 
$ chmod 700 secret.txt   # Owner: rwx  Group: ---  Others: --- 

1.5 Changing Ownership with chown

developers 
$ chown -R memoona myproject/    # Change owner recursively for a whole

Internet Request Flow Explanation
When a user accesses the API from the internet, the request first reaches the AWS EC2 public IP address. The EC2 Security Group allows incoming traffic on port 5000. Docker maps port 5000 from the host machine to the Flask container. The Flask application inside the container receives the HTTP request, processes it, and sends a JSON response back through Docker and AWS networking to the user's browser or curl command.
